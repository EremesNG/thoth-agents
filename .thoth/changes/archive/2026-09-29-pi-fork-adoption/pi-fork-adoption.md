## Exploration

- The user supplied `pi-packages/pi-subagents`, a 110-file MIT fork of j0k3r-dev-rgl/pi-subagents-j0k3r. Explorer inventory found no nested Git repository, dependencies/build outputs or detected credentials. Root committed the intact snapshot as `646c38b` before adaptations, as explicitly requested. Existing upstream whitespace warnings were preserved. The worktree was clean afterward.
- Native discovery tasks `explore_adoption`, `explore_pi_integration` and `explore_fork_runtime` returned terminal read-only findings. There is no CodeGraph index. Existing tools work is recorded separately in `pi-specialist-tools-panel`; its unperformed live smoke is not acceptance evidence for this new migration.
- Root `src/cli/pi-install.ts::PI_PACKAGE_SPECS` and `pi-external-package.ts` identify the external runtime through npm source/name/version. `scripts/setup-pi-local.mjs` currently supplies only the local Thoth root. A local runtime root must flow through parsing, plan, execution and inspection to avoid attempting an unpublished scoped package.
- Root packed artifacts intentionally exclude external implementation trees. The adopted runtime remains a separately packaged source tree. `src/pi.ts` registers Thoth model/tools commands; safe tools persistence lives in `src/cli/pi-tool-config.ts`. `pi-resources.ts` preserves explicit tools, model/effort and mode.
- Fork currently registers singular `/subagent-models`; the user now requests `/subagents-model` with singular model. `model-profiles/data.ts` injects synthetic SDD rows; the profile editor saves `subagents.json`. Resolution is profile, then agent definition, then config default, then root. Retaining native profile precedence avoids competing editors.
- Fork mode resolution is invocation, definition, config, then foreground `task`; continuation retains its prior mode. `UsageStats` already carries usage/cost/context/turns, but tool/compaction/context-capacity projection needs focused verification. The widget currently renders below the editor.
- External Librarian `research_pi_contracts` inspected primary sources: https://github.com/gotgenes/pi-packages/blob/main/packages/pi-subagents/src/ui/agent-widget.ts and widget-renderer.ts; https://github.com/michaelmjhhhh/pi-atelier/blob/main/src/subagent-usage.ts and subagent-cost-history.ts; https://github.com/nicobailon/pi-subagents/blob/main/docs/observability.md. These mutable source links were accessible; immutable Atelier commit lookup was unavailable. Consumer fixtures must verify the described contract rather than assume version equivalence.
- Atelier discovers references through custom session entries `pi-atelier:subagent-metadata`, data `{runIds, paths, asyncDirs}` (string arrays). Per-run `_meta.json` has runId, agent and usage input/output/cacheRead/cacheWrite plus optional numeric cost. Async status owns the run through sessionId matching the root session ID or session file; events use child message_end, matching run/step/agent, observedAt and message.usage.cost.total. No such adapter exists in the fork.

## Intent

Adopt the supplied runtime as `@thoth-agents/pi-subagents`, replace the external j0k3r dependency, use the native model configuration design for models and tools, remove fork-owned SDD, run subagents in background by default, show the requested tree above input, and expose real subagent usage/cost to Atelier.

## Non-goals

- No npm publication, push, automatic version increment, live global installation or changes to unrelated harness behavior.
- No replacement scheduler, copied external runtime inside the root tarball, new SDD workflow, or changes to Thoth's existing SDD ownership.
- No automatic wildcard tool inheritance, bypass of safe tool persistence, fabricated usage, or claims that selected tool names prove runtime availability.
