# Plan contract

**Owner**: root<br>
**Output**: `openspec/changes/<feature>/plan.md`

Start from `templates/plan.md`. Read the project constitution and record a
pre-design Constitution Check. Map each technical choice to FR/SC or confirmed
repository constraints; name affected components, interfaces, exact paths,
migrations, risks, and verification seams. Create `research.md`, `data-model.md`,
`contracts/`, or `quickstart.md` only when each reduces implementation risk.
Repeat the Constitution Check after design against concrete decisions. Any
unjustified failure blocks tasks.
