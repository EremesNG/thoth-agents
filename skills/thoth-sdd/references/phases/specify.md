# Specify contract

**Owner**: root<br>
**Output**: `openspec/changes/<feature>/spec.md`

Start from `templates/spec.md`. Define prioritized stories `US#` that can be
implemented and tested independently. Each story needs a plain-language outcome,
an independent test, and Given/When/Then acceptance scenarios. Use unique,
sequential `FR-###` functional requirements and measurable `SC-###` success
criteria. State assumptions, dependencies, edge cases, and out-of-scope items.
Remain implementation-neutral unless a technical constraint is itself accepted.
Do not advance while a material ambiguity would change scope or architecture.
